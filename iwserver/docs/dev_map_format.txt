Map File Format (Developer Reference)

Map files are plain text stored under iwserver/content/maps/[mode]/ with the .map extension.

Header fields (one per line):
mapname:[name] - The display name of the map.
maxx:[value] - Maximum X coordinate.
maxy:[value] - Maximum Y coordinate.
maxz:[value] - Maximum Z coordinate.

Tile definitions:
tile:x1:x2:y1:y2:z1:z2:tilename - Defines a walkable tile in a rectangular region.

Zone definitions:
zone:x1:x2:y1:y2:z1:z2:zonename - Defines a named zone for player orientation. Zone names are shown when pressing B.

Ambience definitions:
ambience:x1:x2:y1:y2:z1:z2:soundfile - Plays a looping sound in the specified region.

Ladder definitions:
ladder:x:y:z1:z2:mapname - A climbable ladder at the given position connecting two Z levels.

Point of interest definitions:
poi:x:y:z:name - A named location listed by the points-of-interest menu (J).

Turbolift definitions:
turbolift:x1:x2:y1:y2:z1:z2:liftname:level1,z1:level2,z2:... - Declares a turbolift whose control panel occupies the given region (spanning z1..z2 across every level it serves). The trailing fields each name a destination level and its absolute Z, separated by a comma. Level names must not contain a colon or a comma. When a player stands in the panel region and presses Shift+P, a menu offers those levels; selecting one moves the player to that level's Z, announcing every served level passed along the way. Parsed client-side in includes/map.nvgt.

Transition definitions:
transition:x1:x2:y1:y2:z1:z2:destx:desty:destz:label - An interaction point (such as a ship's airlock). When a player stands inside the region and presses Shift+L, they are moved to (destx,desty,destz) and the label is spoken. Coordinates are absolute; the label may contain spaces but not a colon. Transitions are one-way, so a two-way passage needs one at each end. Parsed client-side in includes/map.nvgt.

The map system is initialized with init_mapsystem() on the server. Maps are sent to clients as raw text via the mapdata message.
Live builder safety: Alt+Shift+P (the builder_menu key) edits the authoritative file for the map the developer is currently occupying. The client keeps the network pump active while it loads, validates coordinate ranges and fields before submitting them, and the server independently rejects malformed, cross-map, oversized, nameless, duplicate-mapname, or structurally invalid changes before any write. The required mapname line cannot be deleted, and deleting the current map requires confirmation.

The live builder can place spawns and permanent fixtures at the builder's current position; author rooms, open regions, portals and POI regions; create a rectangular destructible-object preset as one atomic validated update; inspect element counts; validate, reload or undo the current map; export timestamped local snapshots; and teleport to exact build coordinates. Before every append, edit, delete or full-map write, the server stores an in-memory undo point and a durable timestamped copy under administration/map_backups. Undo swaps the current and prior states, allowing a mistaken undo to be reversed once more.
