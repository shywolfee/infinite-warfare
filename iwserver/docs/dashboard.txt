# In-game Dashboard

The dashboard is Infinite Warfare's persistent gameplay interface. It exists so you can manage equipment, conversations, teams, groups, companions, terminal apps and other game systems without becoming disconnected from a live fight.

## Opening and navigation

In Dashboard mode, Tab and Shift+Tab move through game options, the live player list, the selected conversation transcript, the conversation list, its message field, Send and Game keyboard area (Alt+G). Alt+G immediately focuses the game keyboard area, where movement, combat and world-interaction keys work normally.

Alt+F switches between Dashboard mode and Inventory mode. In Inventory mode, Tab and Shift+Tab cycle carried items during gameplay and newly opened forms behave as ordinary standalone screens. Switching modes preserves any unfinished conversation text.

Escape goes back one screen inside dashboard menus by activating that screen's Back, Close or Cancel action. At the dashboard root it returns to the game keyboard area. The separate Escape game menu contains only the choices to resume or leave the match.

## Managing things while fighting

Screens opened through the dashboard retain the shared dashboard controls. You can inspect equipment, groups, companions, terminal apps, announcements or a player's profile, press Alt+G when you need to move or fight, then Tab back to the same open screen and reading position. Player and conversation lists continue updating while another screen is open.

This is intentionally different from a traditional pause menu. An online battle cannot pause, so management remains available without disabling direct game control. Combat input is active only while the game keyboard area has focus, preventing menu shortcuts and combat keys from colliding.

## Shortcuts and conversations

Each dashboard option announces its Alt-key shortcut after its name and description. Option shortcuts activate only while the options list has focus. Shared dashboard controls have their own announced shortcuts, including Alt+G for game control and Alt+S for Send.

An open screen's actions take priority over shared shortcuts. For example, Alt+S starts an arena while its Start action is available; Alt+S still sends chat from the conversation controls. Gameplay chords, including Alt+Shift+G for manual ammunition ejection, are not claimed by form controls while the game keyboard area is focused.

The conversation area exposes global, map, team, group and private conversations as live readable lists. Enter in the message field, Enter or Space on Send, or Alt+S sends the current message. Draft text is retained when you temporarily return to combat or change dashboard modes.

## Touchscreen dashboard controls

- Top band, three-finger hold: open the dashboard, enabling Dashboard mode if needed.
- Top band, three-finger triple-tap and hold: switch between Dashboard mode and Inventory mode.
- Bottom band, two-finger swipe down: return to the game keyboard area in Dashboard mode.
- Two-finger swipe right or left: Tab or Shift+Tab between form controls.

These actions can be rebound in the gesture manager. Form gestures navigate the open screen while a control has focus; gameplay gestures operate normally in the game keyboard area.

## Reading Markdown documents

Help, announcements, release notes and the player manual use the document reader. Up and Down read one line at a time. H jumps to the next heading, K to the next link, L to the next list and T to the next table; Shift reverses those jumps. Ctrl+Home and Ctrl+End reach the document boundaries. F7 opens the heading and link elements list. Enter or Space follows the focused link. Ctrl+Alt+Arrow keys read table cells with their column headings. Tab leaves the document for another form control without discarding the reading position.
