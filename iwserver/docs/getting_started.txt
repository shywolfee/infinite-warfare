# Getting Started

After deployment you receive a random melee weapon, sidearm and primary weapon, plus basic healing and explosives. Automatic starting quickbar assignment can be enabled or disabled in Gameplay options.

## Movement and combat

Use the arrow keys to move and hold Shift with movement to sprint. Control fires, R reloads, Shift+R unloads, A reports ammunition, Shift+A changes fire mode, and Alt+A opens the drawn weapon panel. Each weapon uses its own calibre; there is no alternate ammunition selector.

## Dashboard and inventory

Press I for the categorized inventory. Alt+F switches between Dashboard mode and Inventory mode. Tab and Shift+Tab navigate dashboard controls in Dashboard mode, or cycle carried items in Inventory mode. Alt+G returns to direct game control in Dashboard mode. K and Shift+K cycle inventory categories during gameplay. Number keys activate quickbar slots and Alt+number assigns the selected item.

## Help

Press Shift+H for the help browser. Its weapon, ammunition, attachment, armour and item sections are generated from the live content database. Alt+Enter opens database help for the selected inventory entry. Documents use Markdown: Up and Down read lines, H jumps to headings, K jumps to links, F7 opens the elements list, and Tab moves to another form control.
